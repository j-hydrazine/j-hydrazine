## About

I like building useful things from fuzzy starting points.

Right now, I am exploring how AI agents, product systems, and human-centered tools can make work feel less repetitive and more creative.

I care about clear interfaces, practical automation, and ideas that can actually be shipped, tested, and improved.

- **Agent systems** — tools that can plan, act, verify, and collaborate with people

- **Interactive systems** — small experiments that make software feel alive
